# Como reportar um bug

Um relato útil permite que outra pessoa observe o mesmo problema.

## Antes de abrir a issue

1. Procure relatos semelhantes e PRs relacionadas.
2. Confira a versão instalada e as instruções da versão que você usa.
3. Tente reduzir seu projeto a um exemplo mínimo.
4. Remova credenciais, dados reais de clientes e arquivos privados.

## Estrutura sugerida

```text
Título: comportamento específico que falha

Contexto:
Versão da biblioteca, linguagem, navegador e sistema relevantes.

Passos para reproduzir:
1. ...
2. ...
3. ...

Resultado observado:
Mensagem de erro ou comportamento real.

Resultado esperado:
O que deveria acontecer e em que documentação/exemplo isso se baseia.

Reprodução mínima:
Link público ou trecho pequeno, sem dados privados.

Verificações:
O que já foi testado e o que ainda não foi confirmado.
```

Uma hipótese não é uma causa comprovada. Use frases como “consigo reproduzir com estes passos” e “suspeito deste trecho” para deixar clara a diferença.

Se o projeto tiver um template próprio, use-o. Problemas de segurança podem ter um canal reservado; confira a política do projeto antes de descrever detalhes publicamente.

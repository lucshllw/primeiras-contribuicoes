# Como contribuir com este guia

Sugestões de clareza, correções verificáveis e exemplos pequenos são bem-vindos.

Antes de enviar:

1. Confira se a sugestão já foi apresentada.
2. Explique qual dúvida de iniciante a alteração resolve.
3. Verifique os comandos, os links relativos e as fontes citadas.
4. Use dados fictícios em exemplos e nunca inclua credenciais.
5. Mantenha uma ideia principal por pull request.

Se usar IA, revise o conteúdo e informe a assistência. Não invente resultados de execução nem atribua experiências pessoais a outras pessoas.

Este guia não substitui as regras das comunidades mencionadas. Corrija referências quando os projetos mudarem e diferencie uma PR proposta de uma mudança efetivamente aceita.
